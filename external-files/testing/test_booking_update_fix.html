🔧 Тест исправления обновления бронирований

📋 Проблема

Ошибка 422 (Unprocessable Content) при попытке обновить бронирование в админке.

🚨 Корневые причины:

  • status_id отправлялся вместо status (строкового значения)
  • category_id отправлялся вместо service_category_id
  • client_id, service_point_id отправлялись, но не разрешены для обновления
  • Неправильная загрузка статуса при редактировании (строковый → числовой)

✅ Исправления

1. Backend (контроллер)

✅ В booking_update_params разрешен параметр :status (строковый)

✅ Убраны :client_id, :service_point_id из разрешенных для обновления

2. Frontend (BookingFormPage.tsx)

✅ Добавлено преобразование числовых статусов в строковые при отправке

✅ Исправлено category_id → service_category_id

✅ Убраны client_id, service_point_id при обновлении

✅ Добавлено преобразование строковых статусов в числовые при загрузке
