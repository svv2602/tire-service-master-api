🏛️ Admin TireData API

Тестирование административных функций управления данными поиска шин

🔐 Авторизация администратора

Важно: Для тестирования админских функций необходимо войти как администратор.

📋 Тест 1: Список версий данных

Endpoint: GET /api/v1/admin/tire_data/versions
Назначение: Получение списка всех версий данных поиска шин

Endpoint: GET /api/v1/admin/tire_data/current_version
Назначение: Получение информации о текущей активной версии данных

Endpoint: GET /api/v1/admin/tire_data/statistics
Назначение: Получение детальной статистики по данным поиска шин

🔄 Тест 4: Обновление данных (ОСТОРОЖНО!)

Endpoint: POST /api/v1/admin/tire_data/update
Назначение: Обновление данных поиска шин из CSV файлов
⚠️ ВНИМАНИЕ: Эта операция может изменить данные в системе!

↩️ Тест 5: Откат к предыдущей версии (ОСТОРОЖНО!)

Endpoint: DELETE /api/v1/admin/tire_data/rollback
Назначение: Откат к предыдущей версии данных
⚠️ ВНИМАНИЕ: Эта операция изменит активную версию данных!

Результат отката:

🧹 Тест 6: Очистка старых версий (ОСТОРОЖНО!)

Endpoint: POST /api/v1/admin/tire_data/cleanup
Назначение: Удаление старых версий данных (оставляем последние N)
⚠️ ВНИМАНИЕ: Эта операция безвозвратно удалит старые версии!
