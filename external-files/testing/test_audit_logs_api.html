📊 Тест API аудита системы

📋 Информация о тестировании

Базовый URL: http://localhost:8000/api/v1

Требуется авторизация: Да (Bearer token)

Роли для доступа: admin, manager

Endpoints:

  • GET /audit_logs - Список логов с фильтрами и пагинацией
  • GET /audit_logs/stats - Статистика по активности
  • GET /audit_logs/:id - Детальная информация о логе
  • GET /audit_logs/export.csv - Экспорт в CSV
