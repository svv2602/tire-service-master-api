🤖 Тест Telegram Бронирования

📋 Информация о тесте

Этот тест проверяет работу системы многошагового бронирования через Telegram бота.

Команды для тестирования:

  • /booking - Начать процесс бронирования
  • /start - Главное меню с кнопкой "Создать бронирование"
  • /help - Список команд (включая /booking)

🔍 Проверка данных системы

📝 Шаги процесса бронирования

Шаг 1: Выбор города 🏙️

Ожидается: список городов с сервисными точками в inline клавиатуре

Шаг 2: Выбор услуги 🔧

Ожидается: список категорий услуг

Шаг 3: Выбор сервисного центра 📍

Ожидается: список сервисных точек в выбранном городе

Шаг 4: Выбор даты и времени 📅

Ожидается: календарь на 14 дней вперед, затем выбор времени

Шаг 5: Выбор типа автомобиля 🚗

Ожидается: список типов автомобилей

Шаг 6: Ввод номера телефона 📱

Ожидается: запрос номера телефона + кнопка "Отправить контакт"

Шаг 7: Ввод номера автомобиля 🚙

Ожидается: запрос номера автомобиля

Шаг 8: Комментарий (опционально) 💬

Ожидается: запрос комментария + кнопка "Пропустить"

Подтверждение: Показ всех данных ✅

Ожидается: сводка с кнопками "Подтвердить"/"Отменить"

🎯 Инструкции для тестирования

  1. Отправьте команду /booking в Telegram бот
  2. Проследите все шаги процесса бронирования
  3. Проверьте, что inline кнопки работают
  4. Убедитесь, что ввод текста принимается на соответствующих шагах
  5. Проверьте финальное подтверждение

🚨 Возможные проблемы

  • Отсутствие городов: Проверьте наличие активных сервисных точек
  • Отсутствие услуг: Проверьте наличие активных категорий услуг
  • Ошибки в процессе: Проверьте логи Rails в консоли
  • Не работают кнопки: Убедитесь, что ngrok работает
