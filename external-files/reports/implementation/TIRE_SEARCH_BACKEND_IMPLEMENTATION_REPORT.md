### ⚠️ **Известные ограничения:**
1. **Алиасы в скоупах:** "БМВ тройка" не находит результатов
   - Причина: скоуп `for_model` ищет точное соответствие, не учитывает алиасы
   - Решение: требуется доработка поисковых скоупов

2. **LLM интеграция:** пока только заглушка
   - Для сложных запросов типа "какие шины подойдут для моего автомобиля"
