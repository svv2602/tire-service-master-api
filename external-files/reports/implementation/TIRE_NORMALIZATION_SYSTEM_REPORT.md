## 🔄 ЛОГИКА НОРМАЛИЗАЦИИ

### 1. Алгоритм поиска брендов
```ruby
def find_tire_brand(brand_name)
  normalized_name = normalize_string(brand_name)
  
  # 1. Точное совпадение по нормализованному названию
  brand = TireBrand.find_by(normalized_name: normalized_name)
  
  # 2. Поиск по алиасам
  brand ||= TireBrand.where("? = ANY(aliases)", brand_name).first
  
  return brand
end
```

### 2. Система рейтингов оптимальности
```ruby
def calculate_optimality_score(product)
  score = 0.0
  
  # Рейтинг бренда (40% веса)
  score += (product.tire_brand&.rating_score || 5) * 4.0
  
  # Рейтинг страны (30% веса) 
  score += (product.country&.rating_score || 5) * 3.0
  
  # Премиум сегмент (+10 баллов)
  score += 10.0 if product.tire_brand&.is_premium
  
  # Год производства (10% веса)
  score += year_freshness_score(product.production_year)
  
  # Наличие на складе (+5 баллов)
  score += 5.0 if product.in_stock
  
  return score.clamp(1.0, 100.0)
end
```

### 3. Нормализация строк
```ruby
def normalize_string(str)
  str.to_s.strip.downcase
     .gsub(/[^\p{L}\p{N}\s]/, '') # Убираем спецсимволы
     .squeeze(' ')                # Убираем лишние пробелы
end
```
