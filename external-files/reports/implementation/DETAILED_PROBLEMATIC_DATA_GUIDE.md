## 🎯 ОТВЕТЫ НА ВОПРОСЫ ПОЛЬЗОВАТЕЛЯ

### **❓ "У каких товаров проблемы?"**
**➡️ Кликните на проблемную запись → кнопка "👁️ Посмотреть товары"**

Вы увидите:
- 📦 **Конкретные товары** с проблемным названием
- 🔍 **ID товаров** для поиска в системе  
- 📝 **Оригинальные данные** из прайса поставщика
- 💰 **Цены** и размеры шин

### **❓ "У каких поставщиков проблемы?"**
**➡️ Смотрите колонку "Основные поставщики" в таблице**

Показывает:
- 🏢 **Названия поставщиков** с количеством проблемных товаров
- 📊 **Топ-3 поставщика** по количеству проблем
- 💼 **Общее количество** затронутых поставщиков

### **❓ "Как это выглядит в оригинале загрузки?"**
**➡️ В диалоге товаров колонка "Оригинальные данные"**

Содержит:
- 🏷️ **Бренд:** точное название из XML прайса
- 🚗 **Модель:** оригинальное написание
- 🌍 **Страна:** как указал поставщик

## 🔍 ПРАКТИЧЕСКИЕ ПРИМЕРЫ

### **Пример 1: Анализ проблемной страны "Германия ФРГ"**

**Шаг 1:** Открываем `/admin/normalization/analysis`  
**Шаг 2:** Выбираем "Проблемные страны"  
**Шаг 3:** Видим запись "Германия ФРГ" с 1,130 товарами  
**Шаг 4:** В колонке поставщиков: ТирПлюс (890), АвтоШина (240)  
**Шаг 5:** Кликаем "👁️" для просмотра товаров  

**Что видим:**
- Конкретные шины с этой проблемой
- Оригинальные названия из XML файлов поставщиков
- ID товаров для поиска в базе

**Решение:** Добавляем алиас "Германия ФРГ" → "Германия"

### **Пример 2: Анализ проблемного бренда "Michlen"**

**Проблема:** Поставщик ШинСервис загружает бренд как "Michlen" вместо "Michelin"

**Анализ:**
- 24 товара затронуто
- Все товары от одного поставщика (ШинСервис)  
- Это опечатка в XML файле поставщика

**Решение:** 
1. Добавить алиас "Michlen" → "Michelin"
2. Связаться с поставщиком для исправления в будущих прайсах

### **Пример 3: Множественные поставщики**

**Проблема:** "Kontinental" (неправильное написание Continental)

**Анализ показывает:**
- ТирОпт (156 товаров)
- МегаШина (89 товаров)  
- АвтоЦентр (34 товара)

**Вывод:** Проблема системная - несколько поставщиков делают одну ошибку

## 🛠️ ПРАКТИЧЕСКИЕ ДЕЙСТВИЯ

### **🎯 Приоритизация исправлений:**

**1. Критичные (🔴 100+ товаров):**
- Исправлять немедленно
- Влияют на поиск и фильтрацию
- Критично для пользователей

**2. Важные (🟡 50-99 товаров):**
- Исправлять в течение недели
- Заметное влияние на качество

**3. Внимание (🔵 10-49 товаров):**
- Исправлять по возможности
- Планировать в месячные задачи

**4. Незначительные (🟢 <10 товаров):**
- Низкий приоритет
- Исправлять при наличии времени

### **📞 Работа с поставщиками:**

**Если проблема от одного поставщика:**
1. Добавить алиас для немедленного исправления
2. Связаться с поставщиком
3. Попросить исправить в следующем прайсе
4. Мониторить будущие загрузки

**Если проблема от нескольких поставщиков:**
1. Добавить алиас для исправления
2. Отправить информационное письмо всем поставщикам
3. Добавить проверку в стандарты загрузки

### **🔄 Мониторинг после исправлений:**

1. Запускать нормализацию после добавления алиасов
2. Проверять метрики качества на главной странице
3. Мониторить появление новых проблем при загрузке прайсов

## 💡 ПОЛЕЗНЫЕ СОВЕТЫ

### **🕵️ Диагностика проблем:**

**Вопрос:** Откуда взялась эта проблема?  
**Ответ:** Смотрите колонку "Основные поставщики" - показывает источник

**Вопрос:** Насколько это критично?  
**Ответ:** Цветовая маркировка: красный = критично, синий = можно подождать

**Вопрос:** Что делать если много поставщиков?  
**Ответ:** Системная проблема - нужен алиас + работа со стандартами

### **⚡ Быстрые исправления:**

1. **Опечатки брендов:** Michlen → Michelin, Kontinental → Continental
2. **Названия стран:** USA → США, Германия ФРГ → Германия  
3. **Модели с пробелами:** EcoContact5 → EcoContact 5

### **📊 Анализ трендов:**

- Если одни поставщики дают больше проблем - обучение
- Если проблемы растут - ужесточить контроль прайсов
- Если снижаются - система работает эффективно
