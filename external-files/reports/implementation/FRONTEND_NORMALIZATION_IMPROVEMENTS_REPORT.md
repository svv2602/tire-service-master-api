
**Возможности:**
- 📊 Детальная статистика по брендам, странам, моделям
- ⏱️ Время выполнения нормализации
- 🎯 Визуальный прогресс-бар покрытия
- ⚠️ Предупреждения об ошибках
- 💡 Цветовая индикация результатов

### 2. **NormalizationProgress.tsx** - Прогресс загрузки
```tsx
// Показывает этапы обработки прайса
<NormalizationProgress stage="normalizing" />
```

**Этапы обработки:**
- 🔄 **Uploading** (25%) - Загрузка прайс-листа
- ⚙️ **Processing** (50%) - Обработка товаров
- 🔗 **Normalizing** (85%) - Автоматическая нормализация
- ✅ **Completed** (100%) - Загрузка завершена

### 3. **DataQualityDashboard.tsx** - Панель качества данных
```tsx
// Мониторинг качества нормализации
<DataQualityDashboard 
  metrics={qualityMetrics} 
  onRefresh={handleRefresh}
/>
```

**Метрики качества:**
- 🏷️ **Покрытие брендов** - % товаров с привязанными брендами
- 🌍 **Покрытие стран** - % товаров с определенной страной
- 🚗 **Покрытие моделей** - % товаров с привязанными моделями
- ⭐ **Рейтинги качества** - % товаров с рассчитанными рейтингами

## 🔧 ТЕХНИЧЕСКИЕ ИЗМЕНЕНИЯ

### 1. Обновлены TypeScript интерфейсы

#### `src/api/suppliers.api.ts`
```typescript
// Новые интерфейсы для статистики
export interface UploadPriceStatistics {
  total_items: number;
  processed_items: number;
  created_items: number;
  updated_items: number;
  error_items: number;
  processing_time_ms: number;
}

export interface NormalizationStatistics {
  total_products: number;
  processed: number;
  normalized_brands: number;
  normalized_countries: number;
  normalized_models: number;
  failed: number;
  processing_time_ms: number;
  summary: string;
  error?: string;
}

// Обновлен основной интерфейс ответа
export interface UploadPriceResponse {
  success: boolean;
  message: string;
  statistics?: UploadPriceStatistics;    // ← Новое поле
  normalization?: NormalizationStatistics; // ← Новое поле
  version?: string;
}
```
