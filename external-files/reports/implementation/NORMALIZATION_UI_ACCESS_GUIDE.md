# 🎯 РУКОВОДСТВО: ГДЕ ПРОСМАТРИВАТЬ ДАННЫЕ О НОРМАЛИЗАЦИИ

**Дата создания:** 14 января 2025  
**Статус:** ✅ ГОТОВО К ИСПОЛЬЗОВАНИЮ

## 📍 ЛОКАЦИИ ПРОСМОТРА ДАННЫХ НОРМАЛИЗАЦИИ

### 1. **Главная панель мониторинга** 🔗
**Путь:** `/admin/normalization`  
**Меню:** Справочники → 🔗 Мониторинг нормализации

**Что можно увидеть:**
- 📊 **Панель качества данных** с метриками покрытия
- 🏷️ **Покрытие брендов** - % товаров с привязанными брендами
- 🌍 **Покрытие стран** - % товаров с определенной страной производства
- 🚗 **Покрытие моделей** - % товаров с привязанными моделями  
- ⭐ **Рейтинги качества** - % товаров с рассчитанными рейтингами
- 📈 **Статистика справочников** (33 страны, 91 бренд, 662 модели)
- 🔧 **Быстрые действия** для управления справочниками
- ⚡ **Кнопка запуска нормализации** для ручного запуска

### 2. **При загрузке прайсов поставщиков** 📤
**Путь:** `/admin/suppliers/{id}/upload`  
**Меню:** Управление → Поставщики → [Выбрать поставщика] → "Загрузить прайс"

**Что можно увидеть:**
- 🔄 **Прогресс-бар с этапами**:
  - Загрузка прайс-листа (25%)
  - Обработка товаров (50%)
  - **Автоматическая нормализация (85%)**
  - Загрузка завершена (100%)

- 📊 **Детальная статистика обработки**:
  - Всего товаров
  - Обработано товаров
  - Создано новых
  - Обновлено существующих
  - Время обработки

- 🔗 **Статистика автоматической нормализации**:
  - Количество нормализованных брендов (+X)
  - Количество нормализованных стран (+Y)
  - Количество нормализованных моделей (+Z)
  - Время выполнения нормализации
  - Резюме результатов

### 3. **Управление справочниками** 📚

#### 3.1 **Страны производства шин**
**Путь:** `/admin/countries`  
**Меню:** Справочники → Страны

#### 3.2 **Бренды шин**  
**Путь:** `/admin/tire-brands`  
**Меню:** Справочники → Шинные бренды

#### 3.3 **Модели шин**
**Путь:** `/admin/tire-models`  
**Меню:** Справочники → Модели шин

**Что можно делать:**
- ✅ Просматривать все записи справочников
- ➕ Создавать новые записи
- ✏️ Редактировать существующие
- 🏷️ Управлять алиасами для лучшего поиска
- 🔍 Фильтровать и искать записи

## 🎯 ПРИМЕР ИСПОЛЬЗОВАНИЯ

### Сценарий 1: **Проверка качества данных**
```
1. Перейти в: Справочники → 🔗 Мониторинг нормализации
2. Посмотреть общие метрики качества
3. Если покрытие < 90% - нажать "Запустить нормализацию"
4. Проанализировать рекомендации по улучшению
```

### Сценарий 2: **Загрузка нового прайса**
```
1. Перейти в: Управление → Поставщики → [Выбрать] → Загрузить прайс
2. Загрузить XML файл
3. Наблюдать за прогрессом нормализации в реальном времени
4. Получить детальную статистику результатов
```

### Сценарий 3: **Управление справочниками**
```
1. Перейти в: Справочники → [Выбрать нужный]
2. Добавить новые записи или алиасы
3. Проверить результат в мониторинге нормализации
```

- 🟢 **Отлично (95%+)** - Зеленый цвет
- 🔵 **Хорошо (85-95%)** - Синий цвет  
- 🟡 **Средне (70-85%)** - Желтый цвет

## ⚡ АВТОМАТИЧЕСКИЕ ФУНКЦИИ

### Что происходит автоматически:
1. **При загрузке прайса** - автоматически запускается нормализация
2. **Отображение результатов** - статистика показывается без дополнительных действий
3. **Обновление метрик** - данные обновляются в реальном времени
4. **Предупреждения** - система автоматически показывает рекомендации

### Что можно делать вручную:
1. **Запустить нормализацию** - через кнопку в мониторинге
2. **Обновить данные** - через кнопку Refresh
3. **Добавлять алиасы** - для улучшения качества поиска
4. **Управлять справочниками** - создание, редактирование, удаление

## 🔄 ПРОЦЕСС РАБОТЫ С НОРМАЛИЗАЦИЕЙ

### Ежедневный мониторинг:
```
1. Зайти в админку → Справочники → Мониторинг нормализации
2. Проверить общее качество данных (должно быть > 90%)
3. При необходимости запустить нормализацию
4. Посмотреть рекомендации по улучшению
```

### При загрузке нового прайса:
```
1. Управление → Поставщики → [Выбрать] → Загрузить прайс
2. Загрузить файл и дождаться завершения
3. Проанализировать статистику нормализации
4. При необходимости добавить новые алиасы в справочники
```

### При низком качестве данных:
```
1. Проверить секцию "Рекомендации по улучшению"
2. Перейти в соответствующие справочники
3. Добавить недостающие алиасы или записи
4. Запустить повторную нормализацию
```
