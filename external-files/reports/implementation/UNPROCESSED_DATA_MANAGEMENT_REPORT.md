# 🔍 СИСТЕМА УПРАВЛЕНИЯ НЕНОРМАЛИЗОВАННЫМИ ДАННЫМИ

**Дата реализации:** 14 января 2025  
**Статус:** ✅ ГОТОВО К ПРОДАКШЕНУ

## 📋 КРАТКОЕ РЕЗЮМЕ

Создана **полнофункциональная система для просмотра и управления товарами, которые не смогли быть автоматически нормализованы**. Система позволяет находить проблемные данные, анализировать причины и принимать меры для улучшения качества нормализации.

## 🎯 ОСНОВНЫЕ ВОЗМОЖНОСТИ

### 1. **Просмотр ненормализованных товаров** 📊
- **Фильтрация по типу проблем:** бренды, страны, модели, рейтинги
- **Поиск по названию:** мгновенный поиск по товарам, брендам, моделям
- **Пагинация:** удобное листание больших объемов данных
- **Детальная информация:** все оригинальные данные в удобном виде

### 2. **Анализ проблемных данных** 🔍  
- **Топ-5 проблемных записей** для каждого типа
- **Статистика покрытия** в реальном времени
- **Визуальные индикаторы** отсутствующих полей
- **Группировка по поставщикам**

### 3. **Массовые операции** ⚡
- **Выборочная нормализация** конкретных товаров
- **Массовая нормализация** всех отфильтрованных товаров
- **Пакетная обработка** для оптимизации производительности
- **Прогресс-индикаторы** в реальном времени

### 4. **Управление алиасами** 🏷️
- **Добавление новых алиасов** прямо из интерфейса
- **Создание новых записей** в справочниках
- **Автоматические рекомендации** на основе анализа данных

## 📊 ПРИМЕР ИСПОЛЬЗОВАНИЯ

### Сценарий 1: **Поиск товаров без брендов**
```
1. Перейти: Справочники → Мониторинг нормализации → Просмотр данных
2. Выбрать фильтр: "Без брендов"
3. Увидеть топ-5 проблемных брендов в Alert
4. Просмотреть товары в таблице
5. Выбрать товары для нормализации
6. Нажать "Нормализовать выбранные"
```

### Сценарий 2: **Анализ конкретного поставщика**
```
1. Использовать поиск по названию поставщика
2. Проанализировать паттерны в данных
3. Выявить системные проблемы в прайсах
4. Запустить нормализацию для всех товаров поставщика
```

### Сценарий 3: **Добавление алиасов**
```
1. Найти товары с нераспознанными брендами
2. Выявить паттерны (например, "MICHELIN" vs "Michelin")
3. Перейти в: Справочники → Бренды шин
4. Добавить недостающие алиасы
5. Запустить повторную нормализацию
```
