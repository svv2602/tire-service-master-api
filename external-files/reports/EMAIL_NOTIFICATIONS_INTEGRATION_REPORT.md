### Как использовать СЕЙЧАС:

#### 1. **Отправка подтверждения бронирования**:
```ruby
# В контроллере или сервисе
booking = Booking.find(id)
EmailTemplateMailer.booking_confirmation(booking.id, recipient_email).deliver_now
```

#### 2. **Отправка любого типа уведомления**:
```ruby
# Универсальный метод
variables = {
  'client_name' => 'Иван Петренко',
  'booking_date' => '25.07.2025',
  # ... другие переменные
}
EmailTemplateMailer.send_by_template('booking_confirmation', email, variables).deliver_now
```

#### 3. **Тестирование через API**:
```bash
curl -X POST http://localhost:8000/api/v1/email_test/send_template \
  -H "Content-Type: application/json" \

```
