# 🔒 ОТЧЕТ: Валидация уникальности пар бренд+диаметр для исключений - ЗАВЕРШЕНО

## 📋 Описание задачи

Реализована валидация уникальности комбинаций "бренд+диаметр" для исключений в договоренностях партнеров с поставщиками. Система предотвращает создание дублирующих исключений и предупреждает пользователей о конфликтах.

## ✅ Реализованные возможности

### 🔧 Backend валидация

**Файл:** `app/models/partner_supplier_agreement_exception.rb`

1. **Кастомная валидация:** `unique_brand_diameter_combination`
   - Проверяет уникальность пар бренд+диаметр в рамках одной договоренности
   - Учитывает только активные исключения
   - Исключает текущую запись при редактировании

2. **Логика конфликтов:**
   ```ruby
   # Конфликты "все бренды" с конкретными брендами
   brands_conflict = same_brand || 
                    (brand_id_to_check.nil? && exception.tire_brand_id.present?) ||
                    (brand_id_to_check.present? && exception.tire_brand_id.nil?)
   
   # Конфликты "все диаметры" с конкретными диаметрами
   diameters_conflict = same_diameter ||
                       (diameter_to_check.blank? && exception.tire_diameter.present?) ||
                       (diameter_to_check.present? && exception.tire_diameter.blank?)
   ```

3. **Информативные ошибки:**
   - Детальные сообщения с номерами конфликтующих исключений
   - Отображение брендов и диаметров в читаемом формате
   - Ошибки добавляются к соответствующим полям и общему объекту

## 🔍 Правила валидации

### 1. Конфликты типов "Все"
- **"Все бренды"** конфликтует с любыми конкретными брендами
- **"Все диаметры"** конфликтует с любыми конкретными диаметрами
- **"Все бренды + Все диаметры"** блокирует создание любых других исключений

### 2. Конкретные комбинации
- Одинаковые пары бренд+диаметр запрещены
- Разные бренды с одинаковыми диаметрами разрешены (если нет "все бренды")
- Одинаковые бренды с разными диаметрами разрешены (если нет "все диаметры")

### 3. Активность исключений
- Проверяются только активные исключения (`active: true`)
- Неактивные исключения не участвуют в валидации
- При редактировании текущее исключение исключается из проверки

