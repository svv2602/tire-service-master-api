## 📋 Инструкция для полного тестирования

### **Шаг 1: Получить API ключ OpenAI**
1. Зарегистрироваться на https://platform.openai.com/
2. Создать новый проект
3. Сгенерировать API ключ (начинается с `sk-proj-`)

### **Шаг 2: Установить ключ**

**Вариант A: Через админку (рекомендуется)**
```
http://localhost:3008/admin/system-settings
→ Integrations
→ openai_api_key: sk-proj-your-key-here
→ Сохранить
```

**Вариант B: Через переменную окружения**
```bash
export OPENAI_API_KEY="sk-proj-your-key-here"
```

### **Шаг 3: Проверить подключение**
```bash
rails runner "
service = OpenaiService.new
result = service.test_connection
puts result.inspect
"
```

**Ожидаемый результат:**
```ruby
{:success=>true, :message=>"Подключение к OpenAI API успешно"}
```

### **Шаг 4: Протестировать LLM парсинг**
```bash
curl -X POST http://localhost:8000/api/v1/tire_search \
  -d '{"query":"какие зимние шины подойдут на немецкий седан BMW?"}'
```

**Ожидаемый результат:**
```json
{
  "success": true,
  "car_info": {"brand": "BMW"},
  "seasonality": "winter",
  "parsed_data": {
    "brand": "BMW",
    "seasonality": "winter"
  }
}
```
