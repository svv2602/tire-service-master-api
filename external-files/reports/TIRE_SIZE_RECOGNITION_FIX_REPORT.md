# 🎯 Отчет: Исправление распознавания размеров шин в формате "195 65 на 15"

## 📋 Проблема
При вводе размера шин в формате **"195 65 на 15"** система ошибочно распознавала это как модель автомобиля **"mazda 6"** вместо размера шин **"195/65R15"**.

### 🚨 Корневые причины:
1. **Неточный regex**: Паттерн `/(\d{3})[\s\/]*(\d{2})[\s\/]*[rр]?(\d{2})/` не поддерживал слово "на"
2. **Неправильный приоритет**: Проверка марок автомобилей выполнялась ДО распознавания размеров
3. **Конфликт в словаре**: Модель "6" в `'mazda' => ['3', '6', 'cx-5']` пересекалась с цифрой в размере "65"

## 🛠️ Решение

### 1. **Улучшенные паттерны распознавания размеров**
```ruby
# БЫЛО
if size_match = msg.match(/(\d{3})[\s\/]*(\d{2})[\s\/]*[rр]?(\d{2})/)

# СТАЛО - множественные паттерны с приоритетом
size_patterns = [
  /(\d{3})[\s\/\-]*(\d{2})[\s\/\-]*[rр]?(\d{1,2})/,  # Стандартный: 195/65R15
  /(\d{3})[\s]*(\d{2})[\s]*(?:на|на\s+)[\s]*(\d{1,2})/,  # С "на": 195 65 на 15
  /(\d{2,3})[\s\/\-]+(\d{2})[\s\/\-]+(\d{1,2})/,  # Общий: 195/65/15
]
```

### 2. **Приоритет размеров над марками автомобилей**
```ruby
# Распознавание марок автомобилей - ТОЛЬКО если НЕ найден размер шин
if !intent_types.include?('size_request')
  car_brands = detect_car_brand(msg)
  # ...
end
```

### 3. **Валидация ширины шин**
```ruby
# Проверяем, что это действительно размер шин (ширина от 145 до 345)
width = size_match[1].to_i
if width >= 145 && width <= 345
  parameters[:size] = "#{size_match[1]}/#{size_match[2]}R#{size_match[3]}"
```

### 4. **Исправление конфликтных моделей**
```ruby
# БЫЛО
'mazda' => ['3', '6', 'cx-5', 'cx-3', 'cx-9'],

# СТАЛО - более точные названия
'mazda' => ['mazda 3', 'mazda 6', 'cx-5', 'cx-3', 'cx-9'],
```

### 5. **Дополнительная защита от ложных срабатываний**
```ruby
# Если модель - это число, проверяем контекст размера шин
if model.match?(/^\d+$/) && msg_lower.match?(/\d+[\s\/\-]*\d+[\s\/\-]*\d+/)
  Rails.logger.info "🚫 Пропускаем модель '#{model}' - обнаружен паттерн размера шин"
  next
end
```
