## 🏗️ Архитектурные решения

### 🎯 Логика начисления вознаграждений

1. **Условия срабатывания:**
   - Заказ создан пользователем с ролью `partner` ИЛИ `operator`
   - Статус заказа изменяется на: `submitted`, `confirmed`, `completed`
   - У партнера есть активная договоренность с поставщиком
   - В договоренности есть активные правила вознаграждений

2. **Определение получателя вознаграждения:**
   ```ruby
   if user.partner?
     # Партнер получает вознаграждение сам
     partner = user.partner
   elsif user.operator?
     # Партнер получает вознаграждение за оператора
     partner = user.operator.partner
   end
   ```

3. **Автоматический расчет:**
   - Вызывается `RewardCalculationService.new(order)`
   - Проверяется наличие договоренности и правил
   - Рассчитывается сумма по установленным правилам
   - Создается запись `PartnerReward`

### 🔐 Система доступа

**Политика доступа (PartnerRewardPolicy):**
- ✅ **Администраторы:** видят все вознаграждения
- ✅ **Партнеры:** видят только свои вознаграждения (включая от операторов)
- ❌ **Операторы:** НЕ видят вознаграждения (финансы - прерогатива партнера)
- ❌ **Клиенты:** НЕ видят вознаграждения

**Scope фильтрация:**
```ruby
def resolve
  if user.admin?
    scope.all
  elsif user.partner?
    scope.where(partner: user.partner)
  else
    scope.none  # Операторы и другие роли не видят
  end
end
```

## 📈 Бизнес-логика

### Сценарии использования

1. **Партнер создает заказ через корзину:**
   - Заказ: TireOrder (user: Partner, supplier: X)
   - Вознаграждение начисляется → Partner
   - Partner видит вознаграждение в своем кабинете

2. **Оператор создает заказ через корзину:**
   - Заказ: TireOrder (user: Operator, supplier: X)
   - Вознаграждение начисляется → Partner (владелец оператора)
   - Partner видит вознаграждение в своем кабинете
   - Operator НЕ видит вознаграждения

3. **Клиент создает заказ:**
   - Заказ: TireOrder (user: Client, supplier: X)
   - Вознаграждение НЕ начисляется (клиент не связан с партнером)

## ⚙️ Технические детали

### Коллбэки и триггеры
```ruby
# В TireOrder
after_update :calculate_partner_reward, if: :should_calculate_reward?

private

def should_calculate_reward?
  status_changed? && %w[submitted confirmed completed].include?(status)
end

def calculate_partner_reward
  return unless user&.partner? || user&.operator?
  
  service = RewardCalculationService.new(self)
  
  if service.reward_exists?
    service.recalculate_existing_reward
  else
    service.calculate_and_create_reward
  end
end
```
