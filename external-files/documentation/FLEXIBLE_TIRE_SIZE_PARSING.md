# Гибкий парсинг размеров шин

## 🎯 Проблема

Пользователи могут указывать размеры шин в различных форматах и порядках:
- `"BMW 3 Series 225 50 на 17"`
- `"BMW 3 Series 50 на 17 225"`  
- `"BMW 3 Series на 17 225 50"`
- `"BMW 3 Series 225/50/17"`
- `"Tiguan 55 235 R18"`

Старая система искала параметры в строгом порядке и не распознавала все форматы.

## ✅ Решение

### **Новый алгоритм парсинга**

```ruby
def extract_tire_parameters(query)
  params = { width: nil, height: nil, diameter: nil }
  
  # 1. Ищем диаметр по контекстным подсказкам
  diameter_matches = query.scan(/(?:на\s+|r)(\d{2})\b/i)
  if diameter_matches.any?
    diameter = diameter_matches.last.first.to_i
    params[:diameter] = diameter if diameter >= 13 && diameter <= 24
  end
  
  # 2. Извлекаем все числа
  all_numbers = query.scan(/\b(\d{2,3})\b/).flatten.map(&:to_i)
  
  # 3. Исключаем диаметр и года
  excluded_numbers = []
  excluded_numbers << params[:diameter] if params[:diameter]
  excluded_numbers += query.scan(/\b((19|20)\d{2})\b/).flatten.map(&:to_i)
  
  available_numbers = all_numbers - excluded_numbers
  
  # 4. Определяем ширину (145-335)
  width_candidates = available_numbers.select { |n| n >= 145 && n <= 335 }
  if width_candidates.any?
    params[:width] = width_candidates.first
    available_numbers.delete(params[:width])
  end
  
  # 5. Определяем высоту (25-85)
  height_candidates = available_numbers.select { |n| n >= 25 && n <= 85 }
  if height_candidates.any?
    params[:height] = height_candidates.first
  end
  
  # 6. Диаметр из оставшихся чисел (13-24)
  if params[:diameter].nil?
    diameter_candidates = available_numbers.select { |n| n >= 13 && n <= 24 }
    params[:diameter] = diameter_candidates.first if diameter_candidates.any?
  end
  
  params
end
```

### **Поддерживаемые форматы**

#### **1. Стандартные форматы:**
- ✅ `225/50R17` - классический формат
- ✅ `225/50/17` - со слэшами  
- ✅ `225 50 R17` - с пробелами и R
- ✅ `225 50 на 17` - с русским "на"

#### **2. Любой порядок параметров:**
- ✅ `225 50 17` - ширина, высота, диаметр
- ✅ `50 17 225` - высота, диаметр, ширина
- ✅ `17 225 50` - диаметр, ширина, высота
- ✅ `R17 225 50` - диаметр с R, ширина, высота
- ✅ `на 17 225 50` - диаметр с "на", ширина, высота

#### **3. Контекстные подсказки:**
- ✅ `"на 17"` → диаметр 17
- ✅ `"R18"` → диаметр 18
- ✅ `"r19"` → диаметр 19
