## 🛡️ СИСТЕМА ИЗОЛЯЦИИ ДАННЫХ

### Принципы изоляции:
1. **Партнерская изоляция** - каждый партнер видит только свои данные
2. **Операторские ограничения** - доступ только к назначенным точкам
3. **Автоматическая фильтрация** - система автоматически ограничивает данные
4. **Защита от обхода** - множественные уровни проверки

### Что изолируется:
- 📊 Клиенты и их данные
- 🏢 Сервисные точки
- 📅 Бронирования
- 👥 Операторы
- ⭐ Отзывы
- 📈 Статистика

## 🔧 УПРАВЛЕНИЕ ОПЕРАТОРАМИ (для Партнеров)

### Создание оператора:
1. Перейдите в раздел "Операторы"
2. Нажмите "Добавить оператора"
3. Заполните данные пользователя
4. Укажите позицию и уровень доступа
5. Назначьте на сервисные точки

### Назначение на точки:
1. Выберите оператора
2. Нажмите "Назначить на точки"
3. Выберите нужные сервисные точки
4. Подтвердите назначение

### Управление доступом:
- **Уровень 1-2**: Базовые операции
- **Уровень 3-4**: Расширенные функции
- **Уровень 5**: Максимальные права оператора

### Типы блокировки:
1. **Временная** - на определенный период

### Причины блокировки:

## 🆘 ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ

### Q: Почему я не вижу некоторые данные?
**A:** Ваша роль ограничивает доступ к определенным данным. Это нормальная работа системы безопасности.

### Q: Как получить дополнительные права?
**A:** Обратитесь к администратору системы с обоснованием необходимости расширения прав.

### Q: Что делать при блокировке аккаунта?
**A:** Свяжитесь с администратором для выяснения причин и разблокировки.

### Q: Можно ли изменить свою роль самостоятельно?
**A:** Нет, роли назначаются только администраторами системы.

### Q: Как назначить оператора на новую точку?
**A:** Используйте функцию "Назначить на точки" в разделе управления операторами.
